## 🐛 Troubleshooting

### Le trading ne s'active toujours pas

1. Vérifier `bot_state.json`:
```bash
cat bot_state.json | python3 -m json.tool
```

2. Vérifier les logs:
```bash
sudo journalctl -u novabot --since "1 hour ago" | grep -i "trading\|signal\|strategy"
```

3. Forcer l'activation:
```bash
python3 enable_auto_trading.py
sudo systemctl restart novabot
```

### Toujours aucun trade

1. Analyser les conditions:
```bash
python3 analyze_night.py BTC 24
```

2. Vérifier le Risk Manager:
```bash
python3 diagnostic.py
```

3. Réduire les seuils si nécessaire:
   - ADX threshold: 25 → 20 (dans `strategies.json`)
   - RSI zones: élargir les plages
   - FVG threshold: 0.005 → 0.003
